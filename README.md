# AI/ML Profile Preparation Roadmap

A step-by-step plan for building a strong AI/ML profile, from fundamentals to
job-ready projects and interviews. It is meant for students, career switchers,
and software engineers who want a clear path into machine learning roles.

## What's Inside

- **Daily, weekly, and monthly study plan:** a time-boxed schedule with
  topics, practice, and revision built in.
- **Topic-wise syllabus:** Python, math for ML (linear algebra, probability,
  statistics, calculus), data handling with NumPy and pandas, classical ML,
  deep learning, NLP, computer vision, LLMs, and MLOps basics.
- **Curated resources:** courses, books, documentation, and reading links
  for every topic.
- **Project roadmap:** beginner to advanced project ideas that show up well
  on a portfolio.
- **Profile building:** guidance for GitHub, resume, LinkedIn, Kaggle, and
  blog or paper write-ups.
- **Interview preparation:** ML theory questions, coding practice, system
  design for ML, and case studies.
- **Progress tracker:** mark each topic's status and see overall completion.

## Who It's For

- Beginners starting AI/ML from scratch
- Software developers moving into ML roles
- Students preparing for internships and campus placements

## How to Use

1. Download or clone the repository.
2. Set your start date and follow the daily plan.
3. Build at least one project per phase and publish it on GitHub.
4. Track your progress and revisit weak topics each week.
